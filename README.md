# VoiceTyper — голосовой наборщик текста

Голосовой набор в **любое активное окно** Windows — Telegram, VK в браузере,
Word, заметки, куда угодно: курсор где, там и печатается. Один exe-файл,
установка не нужна, по умолчанию всё распознаётся **локально**, без облака.

Скажите **«напиши привет мир»** — и текст появится в окне, где стоит курсор,
по мере того как вы говорите.

> Существует и в виде плагина для умного дома
> **[Astra](https://github.com/mihailinl/AstraPlugins)**:

## Возможности

- **Живой набор по мере речи** — Vosk слушает постоянно и печатает черновик
  сразу, слово за словом.
- **Автоуточнение после пауз** — как только вы делаете паузу, сегмент
  перепроверяется faster-whisper (int8, CPU): черновик заменяется более
  точным текстом с пунктуацией.
- **Непрерывный набор** — «отправить» нажимает Enter и диктовка
  **продолжается**: не нужно снова говорить «напиши». Завершение — словом
  «закончить» (тоже с Enter).
- **Перенос строки голосом** — «с новой строки» вставляет Shift+Enter:
  в мессенджерах строка переносится, а сообщение **не отправляется**.
- **Голосовые команды** (все слова настраиваются):

  | Команда | Действие |
  |---|---|
  | «напиши …» | начать диктовку |
  | «отправить» | Enter, набор продолжается |
  | «закончить» | Enter и конец диктовки |
  | «отмена» | стереть всё набранное за сессию |
  | «с новой строки» | перенос строки без отправки |

  Слова распознаются нечётко («напишы» тоже сработает) и только в начале или
  конце фразы: «отправить» внутри диктуемого текста отправку не вызовет.
- **Голосовая пунктуация** в офлайн-режиме Vosk: «запятая», «точка»,
  «вопросительный знак», «с новой строки» и другие.
- **5 движков распознавания** на выбор:
  - **faster-whisper** (по умолчанию) — локально, качественно, с пунктуацией;
  - **vosk** — локально, легко, без уточнения;
  - **Яндекс SpeechKit** — облако, стриминг, автоматическая пунктуация;
  - **OpenAI и совместимые** — OpenAI, Groq (бесплатный tier), локальные
    whisper-серверы (настраиваемые Base URL и модель);
  - **Google Cloud Speech-to-Text** — облако, ключ API.
- **Печать не зависит от раскладки** — WinAPI SendInput с Unicode: русские
  буквы вставляются правильно даже с английской раскладкой.
- **Значок в трее** с индикатором состояния (зелёный — слушает, серый —
  выключен): включение/выключение из меню, тултип со статусом.
- **Тёмная и светлая тема**, переключается в настройках.
- **Граф настроек** во вкладке приложения: командные слова, движок, ключи
  облаков, клавиша отправки (Enter / Ctrl+Enter), тайминг коррекции.

## Установка

1. Скачайте `VoiceTyper-v…-windows-x64.zip` со страницы
   [Releases](https://github.com/Voltur792/VoiceTyper/releases) и распакуйте.
2. Запустите `VoiceTyper.exe` — откроется окно и появится значок в трее.
3. При первом запуске скачайте модель: вкладка **«Настройки»** →
   **«Скачать модель Vosk»** (~45 МБ, один раз). Модель faster-whisper
   скачается сама при первом уточнении текста.

Python не нужен. Модели лежат в `models\` рядом с exe — папку можно
переносить вместе с программой. Настройки хранятся в
`%APPDATA%\voice-text-input\settings.json`.

## Использование

1. Поставьте курсор в любое текстовое поле — сообщение Telegram, документ,
   поиск браузера.
2. Скажите «напиши» и диктуйте: текст печатается сразу, после пауз
   уточняется.
3. «отправить» — Enter и продолжение («как дела» допишется дальше),
   «закончить» — Enter и завершение, «отмена» — стереть набранное.
4. Кнопка-микрофон в окне (или значок в трее) включает и выключает
   прослушивание; закрытие окна сворачивает его в трей.

Пример: «напиши**»** → «привет, как дела» → «с новой строки» →
«встречаемся в шесть» → «отправить» → «и не опаздывай» → «закончить».

## Сборка из исходников

```powershell
python -m pip install -r requirements.txt pyinstaller
python -m PyInstaller voice-typer.spec --noconfirm
# результат: dist\VoiceTyper.exe
```

Требуется Python 3.11+ и Windows. Релизы собирает CI по тегу `v*`.
